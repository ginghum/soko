# 灯の底 — The Ember Below

見下ろし型アクションRPG。階層探索とレベリング用の狩場を収録。

## 公開
GitHub Pages: https://ginghum.github.io/soko/

`docs/` の静的ファイルで動作します。既存のセーブデータは同じブラウザの localStorage に保存されます。

## 大型追加版

- 新地域：毒沼の地下水路5階、凍結した鉱山4階、灼熱の廃神殿4階。地下水路→鉱山→神殿はボス討伐で解禁。
- 通常敵6種・地域ボス3体を追加。ボスは計4体で、初回討伐後に直接再戦・変異種戦が可能。
- ボス専用装備8種（武器4・アクセサリー4）。通常・変異種とも装備合計1%、各装備は均等。毎回独立抽選・天井なし。専用品は通常戦利品やガチャから出ない。
- 通常敵のガチャ券率12%（幸運効果で18%）。狩場の強敵1枚、ボス3枚、宝物庫2枚。
- 街の装備ガチャ：N経験結晶80% / R15% / SR4.5% / SSR0.5%。毎回独立抽選、天井・10連確定枠なし。Nはスライム5〜20体分の経験結晶1個。券以外の消費なし。
- 武器8種追加（計19）、アクセサリー12種・2枠、装備効果15種類。通常戦利品の武器は効果がランダムで、工房への納品後に付け替え可能。
- 追加クエスト8件（計18）。宝物庫・行商人・祭壇、調合師の救助と開店、魔法の派生、魔物図鑑と収集報酬を追加。
- 狩場の大群・弾幕・消耗戦ルール。追加ルールは敵EXP+35%・殲滅報酬金+50%。
- 地下水路の緑の筋は毒沼、鉱山の青い筋は移動を遅くする氷床、神殿では周期的に敵が攻撃予兆を発生させる。

## 塔・育成・遊びやすさの更新

- 灯試しの塔30階、5階区切りの再開地点。10・20・30階には鏡刃の番人・星文の司書・虚灯の王が登場。各専用武器は通常・変異種とも1%、天井なし。
- 淵蛇・氷王・不死灰・灯守りの4系列、各3品のセット装備。塔の紋章で交換し、2部位で効果発動。既存のボス装備もセットの部位として利用できる。
- 剣技・魔導・影技の18項目。レベルごとに1ポイント、各2段階・前提あり。街で無料振り直し。
- 武器の保護・分解・レア度/武器種/効果の絞り込み。装備中・保護中の品は売却と分解を防止。
- ガチャ1回につき収集欠片1個。通常アクセサリーや店売り武器と交換。以前の抽選回数も初回移行時に反映。
- JSONバックアップの書き出し・読み込み。内容確認後に復元し、復元前の記録も1件保持。
- 冒険/手応えの切替、序盤の敵配置、同時攻撃数、予兆、階層間回復、薬の回復量を調整。詳細は `BALANCE.md`。

## デバッグ／冒険・主人公選択

タイトルの「はじめから」でモードと主人公を選択できる。従来の記録はデバッグモードとして保持する。

| 設定 | デバッグ | 冒険 |
|---|---:|---:|
| レベルアップに必要なEXP | 従来通り | 50倍 |
| 金貨で買う装備・薬・魔法、鍛冶・行商費用 | 従来通り | 10倍 |
| 敵のHP・攻撃力 | 従来通り | 3倍 |
| 売却価格・敵のEXPやお金・ガチャ券 | 従来通り | 据え置き |

旅人(男)と、白髪ロングの旅人(女)を選択でき、能力は同じ。新主人公は移動・攻撃・回避・被弾の透過スプライトを収録。素材と生成プロンプトは `ART_ASSETS.md`。

デバッグは従来の `ember-below-v1`、冒険は `ember-below-adventure-v1` に別保存する。「はじめから」は選んだ枠だけを置き換え、置き換え前の記録を1件保存する。バックアップを読み込む場合も、その記録のモードへ保存する。

冒険手帳には操作中の探索時間、討伐数、長期の収集目標と討伐補給を表示。4時間以上の育成・探索を目標とするが、時間待ちで内容は解禁しない。所要時間は戦闘・装備収集・攻略方法で変わる。

## 再生成とテスト

`src/expansion.js`、`src/ascent.js`、`src/campaign.js`、`src/discovery.js` は既存ゲームのクロージャ内に組み込む追加コード。変更後は以下を実行します。

```sh
python scripts/build-expansion.py
node --check docs/game.js
node tests/game.test.cjs
node tests/expansion.test.cjs
node tests/ascent.test.cjs
node tests/balance.sim.cjs
node tests/campaign.test.cjs
node tests/adventure.sim.cjs
node tests/discovery.test.cjs
```

ゲーム画面の中央へ自動の案内・報酬ダイアログは出さず、通知は画面外の下部、操作メニューは右側に表示します。

## 経験結晶と銀灯の更新

- 通常敵は35%でスライム5〜20体分（EXP60〜240）の経験結晶を落とす。7体続けて出なければ8体目は確定。ボスは20体分を確定。下部の「経験結晶」で1個・同種全部・全種類を使用できる。
- 銀灯スライムは迷宮・地域の通常階で25%、狩場の各群で18%の出現抽選。HP8、武器で通常1ダメージ、魔法・毒無効。発見後17秒で逃走し、倒すと100体分（EXP1200）の銀灯の大結晶を必ず落とす。狩場の殲滅条件には含めない。
- 冒険の金貨支出を30倍から10倍へ。25体討伐ごとに500G・券1枚・10体分の経験結晶1個の手当を街の冒険手帳で受け取れる。
- 雷槍・毒霧・風刃・灯の結界・生命の滴・隕火を追加し、魔法は計10種。武器6種・防具3種・アクセサリー4種も追加（計32武器・11防具・20アクセサリー）。
- 開始時の命名と街の手帳での改名に対応。タイトルからモードの倍率・制作意図の説明を削除。旧セーブは名前未指定・結晶0個として移行する。

## キャラクターデザイン更新

追加地域と塔の敵・ボス、銀灯スライムの13種を専用スプライト化。薬師・調合師・行商人にも専用デザインを追加。計16キャラクター・64ポーズ、透過WebP4枚を収録。敵図鑑にも専用画像を表示。生成仕様と対応表は `ART_ASSETS.md`、描画実装は `src/characters.js`。再生成は従来どおり `python scripts/build-expansion.py`。

## 探索・戦闘・操作の改装

- 古灯の迷宮6階、地下水路8階、氷鉱山7階、廃神殿7階。ボスを新しい最深部へ移動し、救助・既存の討伐記録は保持。塔は30階のまま。
- 通常敵の速度×1.45（最低60）、攻撃間隔×0.68、攻撃力×1.35。ボスは速度×1.65（最低85）、攻撃間隔×0.58、攻撃力×1.5。攻撃予兆は通常0.72〜0.8秒・ボス0.85秒、同時予兆は最大3体。ボス円範囲×1.4、放射弾速245、射撃弾速275〜320。HPそのものへの追加倍率はなし。
- 防具を着ていても攻撃力の24%以上を防御計算の下限にする。一撃の最大HP22%/32%上限と回避の無敵は維持。
- 階段、塔突破、狩場殲滅でHP/MPを自動回復しない。階段と塔で毒も解除しない。薬・回復魔法・街での休息を利用する。
- 狩場は全滅後2秒で自動連戦。メニュー中はカウント停止。銀灯スライムが残っている場合は消さずに待つ。
- PC：EnterまたはShiftで回避、Spaceで魔法。矢印/WASDで魔法・道具を選びEnterで発動、1〜9/0で魔法を直接発動、Escで閉じる。名前やバックアップ入力中はゲームのキー操作を無効化。
- 全32武器の専用画像を追加。旅の記録から更新説明を削除。
- 回帰テスト：`node tests/challenge.test.cjs`。既存5本のテストも現行の階層・戦闘ルールで確認。

## 装備ドロップ調整

敵の装備は通常敵・狩場の強敵・銀灯スライム・ボスすべて1体につき合計1%で独立抽選。狩場の殲滅確定武器と守護者の確定武器を廃止。素材・経験結晶・券・殲滅時の鉱石や薬・宝物庫・購入・交換は据え置き。旧セーブの抽選カウンターは互換性のため保持するが確率には使わない。

## 奥義とキーボード操作

- 剣技「暁光断」は周囲への大斬撃と短い無敵。魔導「星灯崩陣」は3回の範囲魔法と敵弾消去。影技「影縫い・月蝕」は7秒の武器強化と周囲の鈍足。
- 冒険ではLv.8到達または水路の三頭蛇討伐後、対応系統へ4ptの育成と習得2ptで取得。街のスキルツリーで習得・無料振り直し。MPと35〜45秒の再使用時間で連発を制限し、習得と残り時間は保存する。
- Spaceで魔法・道具、Enter/Shiftで回避、Qで奥義、Eで調べる、Iで装備、Xで経験結晶、Rで帰還、Hで遊び方。メニューは矢印/WASD・Tabで選択、Enter/Spaceで決定、Escで閉じる。名前・バックアップの入力は通常どおり。
- 街はTで施設一覧。1迷宮、2狩場、3塔、4店、5鍛冶、6魔法、7ギルド、8ガチャ、9スキル、0地域探索。V図鑑、B調合屋、J冒険手帳、Kボス再戦にも対応。
- 階段はE→Enterで移動。塔の突破後はN→Enterで続行。タイトルの開始・主人公選択や購入・売却・バックアップもキーボードで操作できる。
- 追加モジュールは `src/mastery.js`、回帰テストは `node tests/mastery.test.cjs`。

## 灯籤の狩場と地図の記憶

- 狩場メニューから専用の灯籤狩場へ。灯籤ミミックはガチャ券1枚、5群ごとの大型個体は3枚を確定で落とす。全滅後2秒で自動連戦。通常狩場とは最高群数を分けて記録する。装備1%の抽選と経験結晶は維持。
- 地域・階層ごとの探索済みタイルを保存し、帰還・再入場・再読み込み・バックアップ復元後に再表示する。現在の視界と探索済み範囲は分離。通常階・ボス再戦・塔・狩場も別記録。3秒ごとの更新、移動/保存時、ページを離れる時に記録する。更新前に消えた地図は復元対象外。
- 全要素のタップハイライトとゲーム部分の文字選択・長押しメニューを無効化。名前やバックアップの入力/コピー、メニューのスクロール、キーボードのフォーカス表示は維持。
