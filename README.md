# 灯の底 — The Ember Below

見下ろし型アクションRPG。階層探索とレベリング用の狩場を収録。

## 公開
GitHub Pages: https://ginghum.github.io/soko/

`docs/` の静的ファイルで動作します。既存のセーブデータは同じブラウザの localStorage に保存されます。

## 大型追加版

- 新地域：毒沼の地下水路5階、凍結した鉱山4階、灼熱の廃神殿4階。地下水路→鉱山→神殿はボス討伐で解禁。
- 通常敵6種・地域ボス3体を追加。ボスは計4体で、初回討伐後に直接再戦・変異種戦が可能。
- ボス専用装備8種（武器4・アクセサリー4）。各装備は通常5%、変異種8%。固有装備が29回出なければ30回目に1個確定し、その際は未入手を優先。専用品は通常戦利品やガチャから出ない。
- 通常敵のガチャ券率12%（幸運効果で18%）。狩場の強敵1枚、ボス3枚、宝物庫2枚。
- 街の装備ガチャ：通常R70% / SR25% / SSR5%。SR以上が出ずに10回目、SSRが出ずに50回目は確定。単発・10連共通のカウントを自動保存。券以外の消費なし。
- 武器8種追加（計19）、アクセサリー12種・2枠、装備効果15種類。通常戦利品の武器は効果がランダムで、工房への納品後に付け替え可能。
- 追加クエスト8件（計18）。宝物庫・行商人・祭壇、調合師の救助と開店、魔法の派生、魔物図鑑と収集報酬を追加。
- 狩場の大群・弾幕・消耗戦ルール。追加ルールは敵EXP+35%・殲滅報酬金+50%。
- 地下水路の緑の筋は毒沼、鉱山の青い筋は移動を遅くする氷床、神殿では周期的に敵が攻撃予兆を発生させる。

## 塔・育成・遊びやすさの更新

- 灯試しの塔30階、5階区切りの再開地点。10・20・30階には鏡刃の番人・星文の司書・虚灯の王が登場。各専用武器は通常5%・変異種8%、30周救済あり。
- 淵蛇・氷王・不死灰・灯守りの4系列、各3品のセット装備。塔の紋章で交換し、2部位で効果発動。既存のボス装備もセットの部位として利用できる。
- 剣技・魔導・影技の18項目。レベルごとに1ポイント、各2段階・前提あり。街で無料振り直し。
- 武器の保護・分解・レア度/武器種/効果の絞り込み。装備中・保護中の品は売却と分解を防止。
- ガチャ1回につき収集欠片1個。通常アクセサリーや店売り武器と交換。以前の抽選回数も初回移行時に反映。
- JSONバックアップの書き出し・読み込み。内容確認後に復元し、復元前の記録も1件保持。
- 冒険/手応えの切替、序盤の敵配置、同時攻撃数、予兆、階層間回復、薬の回復量を調整。詳細は `BALANCE.md`。

## デバッグ／冒険・主人公選択

タイトルの「はじめから」でモードと主人公を選択できる。従来の記録はデバッグモードとして保持する。

| 設定 | デバッグ | 冒険 |
|---|---:|---:|
| レベルアップに必要なEXP | 従来通り | 50倍 |
| 金貨で買う装備・薬・魔法、鍛冶・行商費用 | 従来通り | 30倍 |
| 敵のHP・攻撃力 | 従来通り | 3倍 |
| 売却価格・敵のEXPやお金・ガチャ券 | 従来通り | 据え置き |

茶髪の旅人と、白髪ロングの女勇者を選択でき、能力は同じ。新主人公は移動・攻撃・回避・被弾の透過スプライトを収録。素材と生成プロンプトは `ART_ASSETS.md`。

デバッグは従来の `ember-below-v1`、冒険は `ember-below-adventure-v1` に別保存する。「はじめから」は選んだ枠だけを置き換え、置き換え前の記録を1件保存する。バックアップを読み込む場合も、その記録のモードへ保存する。

冒険手帳には操作中の探索時間、討伐数、長期の収集目標と討伐補給を表示。4時間以上の育成・探索を目標とするが、時間待ちで内容は解禁しない。所要時間は戦闘・装備収集・攻略方法で変わる。

## 再生成とテスト

`src/expansion.js`、`src/ascent.js`、`src/campaign.js` は既存ゲームのクロージャ内に組み込む追加コード。変更後は以下を実行します。

```sh
python scripts/build-expansion.py
node --check docs/game.js
node tests/game.test.cjs
node tests/expansion.test.cjs
node tests/ascent.test.cjs
node tests/balance.sim.cjs
node tests/campaign.test.cjs
node tests/adventure.sim.cjs
```

ゲーム画面の中央へ自動の案内・報酬ダイアログは出さず、通知は画面外の下部、操作メニューは右側に表示します。
