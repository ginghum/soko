# 灯の底 — The Ember Below

見下ろし型アクションRPG。階層探索とレベリング用の狩場を収録。

## 公開
GitHub Pages: https://ginghum.github.io/soko/

`docs/` の静的ファイルで動作します。既存のセーブデータは同じブラウザの localStorage に保存されます。

## 大型追加版

- 新地域：毒沼の地下水路5階、凍結した鉱山4階、灼熱の廃神殿4階。地下水路→鉱山→神殿はボス討伐で解禁。
- 通常敵6種・地域ボス3体を追加。ボスは計4体で、初回討伐後に直接再戦・変異種戦が可能。
- ボス専用装備8種（武器4・アクセサリー4）。各装備は通常5%、変異種8%。固有装備が29回出なければ30回目に1個確定し、その際は未入手を優先。専用品は通常戦利品やガチャから出ない。
- 通常敵のガチャ券率12%（幸運効果で18%）。狩場の強敵1枚、ボス3枚、宝物庫2枚。
- 街の装備ガチャ：通常R70% / SR25% / SSR5%。SR以上が出ずに10回目、SSRが出ずに50回目は確定。単発・10連共通のカウントを自動保存。券以外の消費なし。
- 武器8種追加（計19）、アクセサリー12種・2枠、装備効果15種類。通常戦利品の武器は効果がランダムで、工房への納品後に付け替え可能。
- 追加クエスト8件（計18）。宝物庫・行商人・祭壇、調合師の救助と開店、魔法の派生、魔物図鑑と収集報酬を追加。
- 狩場の大群・弾幕・消耗戦ルール。追加ルールは敵EXP+35%・殲滅報酬金+50%。
- 地下水路の緑の筋は毒沼、鉱山の青い筋は移動を遅くする氷床、神殿では周期的に敵が攻撃予兆を発生させる。

## 開発・検証

`src/expansion.js` は既存ゲームのクロージャ内に組み込む追加コード。変更後は以下を実行します。

```sh
python scripts/build-expansion.py
node --check docs/game.js
node tests/game.test.cjs
node tests/expansion.test.cjs
```

ゲーム画面の中央へ自動の案内・報酬ダイアログは出さず、通知は画面外の下部、操作メニューは右側に表示します。
